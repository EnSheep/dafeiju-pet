这份文档只说一件事：**你手上有一个新的绿幕动作视频，怎么把它变成桌宠里能播的动画。**

## 1. 推荐做法：一条命令

在仓库根目录（`C:\Users\lianzhi\Documents\deepseek-harness\default-workspace`）打开终端：

```powershell
py -3 cat-pet\tools\add_action.py "C:\Users\lianzhi\Downloads\新动作.mp4" --name 点击回应-元气挥手
```

它会自动做四件事：

1. **抠背景**（`key_v2.py`）：把绿幕变透明，顺手做 despill，边缘不发绿；
2. **对齐身材**（`place_webm.py`）：按 `1.664612` 倍统一缩放、水平居中、脚底对齐同一条线，保证和待机动作一样高；
3. **压播放版**（`encode_thumbs.py`）：2160×1215 母版 → 640×360 的 VP9-alpha；
4. **部署**：拷进 `~/.dsh/dsh-pet/main-animation/webm/<名字>.webm`。

常用参数：

```powershell
# 视频右下角有平台水印（KlingAI / 豆包 / 即梦 都可能有），用矩形遮掉：
py -3 cat-pet\tools\add_action.py "...\新动作.mp4" --name 原地小憩沉眠 --mask 1040,650,1280,720

# 动作本身不循环（比如一次性挥手），不要做首尾混合：
py -3 cat-pet\tools\add_action.py "...\新动作.mp4" --name 点击回应-元气挥手 --blend 0

# 只想生成、暂时不部署：
py -3 cat-pet\tools\add_action.py "...\新动作.mp4" --name 测试动作 --no-deploy
```

`--mask` 的坐标是 `x1,y1,x2,y2`（像素，左上角原点），可以写多次遮多个地方。
不知道水印在哪？先用播放器截图看一眼，或者直接看 `cat-pet\out\<名字>-keyed.png` 预览图。

## 2. 手工做法（不想用脚本时）

```powershell
$py = 'C:\Users\lianzhi\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe'

# ① 抠背景 → 透明 webm
& $py cat-pet\tools\key_v2.py "C:\...\新动作.mp4" --webm cat-pet\out\新动作-keyed.webm --blend 8

# ② 统一身材、居中、脚底对齐 → 2160×1215 母版
& $py cat-pet\tools\place_webm.py cat-pet\out\新动作-keyed.webm --out dsh-pet\step03\新动作.webm

# ③ 压 640×360 播放版
& $py cat-pet\tools\run_script_serial.py dsh-pet\scripts\encode_thumbs.py

# ④ 部署
Copy-Item 'dsh-pet\step04\新动作.webm' "$env:USERPROFILE\.dsh\dsh-pet\main-animation\webm\新动作.webm" -Force
```

最后**重开 DSH**（关掉再打开，插件只在启动时扫描素材）。

## 3. 出片时的硬性要求（照着做，能省掉 90% 的返工）

| 要求 | 为什么 |
| --- | --- |
| 10 秒、16:9、24fps | 插件的播放和归一化按这个规格来，别的帧率会被重采样 |
| 背景是**纯色绿幕**（`#00FF00` 最稳，绿豆沙绿也行） | 色键靠色相判断，花背景抠不干净 |
| 角色**全程在画面中间**，不要走位 | 动画是静止坐姿/站位，走位会和桌宠位置打架 |
| 脚底始终在同一条水平线 | 归一化按脚底对齐，忽高忽低会「上下弹」 |
| 首帧 = 末帧（循环类动作） | 否则每次循环都会一跳；实在做不到就交给 `--blend 8` 抹一下 |
| 不要有地面阴影、不要有文字 | 阴影会被抠成脏边，文字会跟着角色一起动 |
| 角色大小、朝向保持一致 | 和现有待机动作并排时，大小差一眼就看出来 |

## 4. 把新动作接进配置

素材放进去只是「能播」，还要在配置里登记「什么时候播」。改 `C:\Users\lianzhi\.dsh\dsh-pet\main-config.jsonc`：

```jsonc
"animations": {
  "idle": ["待机呼吸休闲"],                       // 待机池
  "clicks": ["点击回应-元气挥手"],                 // 点一下宠物时随机抽
  "drag": ["被鼠标拖拽悬空反馈"],                  // 抓着晃的时候
  "turn": ["东张西望"],                           // 转身时（要求播完会翻面）
  "moves": { "default": { ... }, "actions": [{ "name": "螃蟹走路" }] },
  "categories": [
    { "id": "小动作", "weight": 10, "actions": ["原地小憩沉眠", "哈欠连天"] }
  ]
}
```

三条规则（踩过坑）：

1. **整段替换**：你写了 `animations` 就整段用你的，没写的子键**不会**从内置默认补回来 —— 想要 `sleep` 就自己写，不想有睡觉就别写。
2. **不能留空池**：`[]` 或 `""` 会让播放端拿到 `undefined`。暂时不想触发的池子，**填一个已经存在的动画名**（比如 `["待机呼吸休闲"]`）最安全。
3. **权重和 = 100**：`animationWeights` 里 `idle + turn + move` 加上各分类 `weight` 必须正好 100；`turn/move` 写 0 就不会自动转身/走动（没素材时建议写 0，否则会「滑行」）。

## 5. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 点了没反应、日志里 404 | 动作名和文件名不一致（中文名要完全一致，不带 `.webm`） |
| 换了素材但画面没变 | 没重开 DSH；插件启动时才扫素材目录 |
| 角色明显变大/变小 | 出片时角色占比和上一条不同；用 `--scale` 手动调（默认 1.664612） |
| 头顶有一团被算进身高、整体缩小 | `place_webm.py --min-row` 调大一点（默认 80），把气泡/特效行排除 |
| 边缘一圈绿光 | 背景不是纯绿或光照不均；`key_v2.py --feather` 调软一点，或重出更干净的绿幕 |
| 循环处一跳 | 出片时首尾帧不一致；加 `--blend 8`，或改成首尾同帧生成 |
| 水印还在 | 加 `--mask x1,y1,x2,y2` |
| 走路时像在滑 | `turn/move` 权重不为 0 但又没有走路素材；改成 0，或老老实实做走路动画 |

## 6. 后续建议的动作优先级

按「用户能感知到」的程度排：

1. **点击回应**（5 条里先做 2 条：挥手、开心跃动）—— 点它一下有反应，最容易被注意到；
2. **哈欠连天 / 超大伸懒腰** —— 和打盹是一套，凑成「犯困三部曲」；
3. **东张西望** —— 转身要用，做一条就够；
4. **螃蟹走路 / 原地漂浮踏步** —— 走路素材，做了才能开移动；
5. 睡觉三段（开始/循环/起来）—— 想让右键「睡觉」回来时才做。
